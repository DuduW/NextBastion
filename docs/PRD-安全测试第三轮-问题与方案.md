> 目标：https://192.168.110.114（FastAPI + SPA + SSH/RDP 网关 + MySQL + 389-DS）
> 范围：Phase1 侦察（端口/TLS/头）→ Phase2-3 全 API 面（认证/授权/注入/JWT/越权/XSS/CSRF/系统层）

## 1. 执行摘要

第三轮安全测试完成。**核心 API 安全面表现良好**：SQL 注入（全参数化）、JWT 攻击（签名篡改/alg=none 全拒）、垂直越权（user→admin 端点全 403）、未认证访问（全 401）、用户枚举（统一文案）、路径穿越变体（全拦截）、CORS（无反射）均通过——前两轮 9 项修复经受住了复测。

本轮发现 **8 项新问题**（2 HIGH / 3 MED / 3 LOW），集中在**暴露面与纵深防御**层面，无核心逻辑漏洞。

## 2. 发现清单（按优先级）

### P1 🔴 HIGH：FastAPI 交互式文档对外无鉴权暴露
- **证据**：`GET /docs`、`/redoc`、`/openapi.json` → 200（无需认证），返回全部 API 端点蓝图
- **风险**：攻击者获得完整接口清单与参数结构，定向构造攻击，侦察成本降为零
- **方案**：生产环境关闭（main.py 启动参数 `docs_url=None, redoc_url=None, openapi_url=None`），或加 admin 鉴权中间件
- **工作量**：0.5h

### P2 🔴 HIGH：uvicorn 8000 直连通道绕过 nginx 防护层
- **证据**：`0.0.0.0:8000` 监听 + firewalld 放行 `8000/tcp`；HTTP 明文（无 TLS）
- **风险**：① 绕过 nginx 的 TLS/安全头/未来限速层；② 凭据明文传输可被内网嗅探
- **方案**：双管齐下——uvicorn 绑定改 `127.0.0.1:8000`（systemd ExecStart）；firewalld 移除 `8000/tcp` 放行规则
- **工作量**：0.5h

### P3 🟠 MED：health 端点泄露精确版本号
- **证据**：`GET /api/v1/health`（无鉴权）→ `{"status":"up","version":"1.0.0"}`
- **风险**：版本指纹供攻击者匹配已知漏洞
- **方案**：响应移除 `version` 字段（或仅 admin 可见）
- **工作量**：0.2h

### P4 🟠 MED：admin 账号未启用 TOTP 双因子
- **证据**：DB `admin.is_mfa_enabled=0`；实测登录不带 totp 直接返回 token
- **风险**：最高权限账号仅单因子保护；密码泄露即失守
- **方案**：运营动作——admin 登录后立即绑定 TOTP（用户管理页开启 MFA）；代码层可加"admin 角色强制 MFA"策略开关
- **工作量**：运营 5min / 强制开关 1h

### P5 🟠 MED：并发登录会话数无上限
- **证据**：同一账号 12 次并发登录全部成功，12 个有效 token 并存
- **风险**：token 被窃取后无法通过"挤下线"感知；横向滥用无成本
- **方案**：单用户有效 access_token 并存上限（如 5）——新签发时淘汰最旧（jti 黑名单或 Redis 会话表）；或登录互斥提示
- **工作量**：1.5h

### P6 🟡 LOW：XSS 防御为单层（仅前端 esc）
- **证据**：资产名/节点名可存储 `<script>`/`<img onerror>` 载荷（API 200 入库）；浏览器实测资产/节点/我的资产三页 **未触发**（前端 esc() 兜住）
- **风险**：防御依赖每个渲染点都记得 esc——未来新增页面/字段遗漏即爆；审计页 command_text 原文回显同类
- **方案**：纵深防御——服务端入库净化（hostname/name 等展示字段 strip HTML 标签或转义后存储），前端保持现有 esc
- **工作量**：1h

### P7 🟡 LOW：数据库/目录服务全网卡监听
- **证据**：`*:3306`、`*:389`、`*:636`、`*:33060` 监听 0.0.0.0（防火墙当前未放行，外网/跨段不可达）
- **风险**：防火墙规则一旦误开放即刻暴露；本机多网卡场景横向可达
- **方案**：MySQL `bind-address=127.0.0.1`；389-DS 仅保留 LDAPS（389 明文端口关闭或绑回环）——堡垒机为单机架构，无远程访问需求
- **工作量**：0.5h（需重启服务，低峰执行）

### P8 🟡 LOW：临时凭据接口探测面
- **证据**：`POST /temp-cred` 对已授权资产可发起认证尝试（返回 ticket），无独立频率限制
- **风险**：被授权用户可借堡垒机对目标资产做受策略约束内的口令探测（审计有记录）
- **方案**：temp-cred 失败次数按 用户+资产 维度限速（如 5 次/10 分钟）；audit 告警接入
- **工作量**：1h
