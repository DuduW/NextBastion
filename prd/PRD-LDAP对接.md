## 1. 背景与目标

### 1.1 背景
- 公司已有统一账号目录（OpenLDAP 为主，预留 AD 兼容），运维人员账号在目录中统一管理。
- 当前堡垒机为本地账号体系，新员工需二次建户、离职需两处禁用，存在**账号不同步的窗口风险**。
- 等保审计要求「账号唯一来源可追溯」，目录统一认证是标准答案。

### 1.2 目标
1. 运维用户使用**目录账号密码直接登录堡垒机**（首次登录自动建户，JIT）。
2. **目录组 → 堡垒机角色/用户组**自动映射：入组即授权、移组即失权。
3. 本地 `admin` 保留为**保底账号**（目录故障时仍可登录管理）。
4. 全程可审计：目录登录、同步动作、映射变更均入审计日志。

### 1.3 非目标（明确不做）
- 目录写入（堡垒机不改 LDAP 数据，只读消费）。
- LDAP 用户在本系统内改密（密码变更走目录侧）。
- OAuth2/OIDC/SAML（本期不做，留 V2）。

## 2. 术语

| 术语 | 说明 |
|------|------|
| LDAP Server | 外部目录服务，`ldap://host:389` 或 `ldaps://host:636` |
| Base DN | 检索根，如 `dc=example,dc=com` |
| Bind DN | 堡垒机绑定账号（只读服务账号），如 `cn=readonly,dc=example,dc=com` |
| User Filter | 用户对象过滤，如 `(objectClass=inetOrgPerson)`（AD：`(objectClass=user)`） |
| Login Attr | 登录名属性：OpenLDAP 常用 `uid`，AD 常用 `sAMAccountName` |
| memberOf | 用户所属组属性（OpenLDAP 需 memberof overlay；AD 原生） |
| JIT | Just-In-Time provisioning，首次认证通过即自动建户 |

## 3. 核心设计

### 3.1 认证流程（登录时）

```
用户输入 目录账号/密码
  ├─ 命中本地账号(admin 等 local 类型)? → 走本地密码+TOTP 原流程
  └─ 目录账号:
       ① 服务号 Bind LDAP（LDAPS/StartTLS）
       ② 按 Login Attr 搜用户 DN（User Filter 限定）
       ③ 用户 DN + 输入密码 直 Bind 验证（不落明文，不中转存储）
       ④ 首次通过 → JIT 建户（username/display_name/email 快照 + auth_source='ldap'）
       ⑤ 拉 memberOf → 组映射 → 得出角色 role + 本地用户组
       ⑥ 二次因子：目录用户默认强制 TOTP（首次登录引导绑定，与本地用户同体验）
```

关键决策：
- **D1 密码不落地**：仅做 LDAP Bind 校验，不存储、不哈希目录密码。
- **D2 本地优先级**：同名冲突时本地账号优先，目录账号带 `auth_source='ldap'` 标记隔离。
- **D3 二次因子不豁免**：目录认证只替代「第一因子」，TOTP 仍强制（等保双因子硬要求）。

### 3.2 组映射（授权联动）

| 映射类型 | 规则示例 | 效果 |
|----------|----------|------|
| 角色映射 | `cn=bastion-admins,ou=groups,…` → `admin` | 入组即管理员 |
| 角色映射 | `cn=bastion-auditors,…` → `auditor` | 入组即审计员 |
| 默认角色 | 未命中任何映射 → `user` | 最小权限原则 |
| 用户组映射 | `cn=infra,…` → 本地组 infra | 组成员自动继承该组全部五维授权策略 |

- 映射关系可配多条；**角色映射优先级高于默认角色**。
- 移出目录组 → 下次登录/下轮同步即降权/移组（先降角色再清组）。
- 授权策略仍由本地五维体系承载，LDAP 只管「人」和「角色/组归属」。

### 3.3 同步策略（双通道）

| 通道 | 触发 | 范围 | 用途 |
|------|------|------|------|
| 登录时实时 | 每次目录登录 | 单用户 memberOf | 即时生效授权 |
| 定时全量 | 每日 03:40（复用 timer 体系） | 全部映射组 | 离职降权兜底 |

- 全量同步发现目录中已消失的 JIT 用户：**标记 `suspended`（禁用登录）而非删除**，审计日志保留。
- 同步结果（新增/更新/禁用数量）写审计 + 仪表盘展示。

### 3.4 安全设计

| 项 | 要求 |
|----|------|
| 传输 | 强制 LDAPS(636) 或 StartTLS(389)；纯 389 明文**拒绝**（可显式勾选"内网豁免"才允许，默认关） |
| 证书 | LDAPS 校验 CA（可上传 CA 证书或选"仅内网自签跳过校验"开关，默认校验） |
| Bind 密码 | AES-256-GCM 加密存储（复用托管凭据体系），接口零回显 |
| 密码保存语义 | **留空 = 保留旧密码**（不回显字段的标配语义）；填新值 = 更新；传 `-` = 显式清空（匿名 bind）。⚠️ 2026-10-13 修复：旧逻辑"密码框留空存空密码"导致正常编辑其他配置项时静默冲掉 Bind 密码，同步报 `password is mandatory in simple bind` |
| 锁定联动 | 目录连续失败同样计入 fail_count → 5 次锁 15 分钟（防目录侧爆破） |
| 保底 | 本地 admin 永不目录化；LDAP 服务故障时清晰报错不挂死登录页 |

## 4. 功能清单（M1 范围）

| # | 功能 | 说明 |
|---|------|------|
| F1 | LDAP 连接配置 | 系统设置→目录认证：URL/Base DN/Bind DN/密码/加密方式/CA |

| F7 | 定时同步 | 每日 03:40 systemd timer |
| F8 | JIT 建户 + 首登 TOTP 引导 | 目录用户首次登录 → 强制绑 TOTP（复用现有绑定流） |

| F10 | 审计 | 目录登录/同步/映射变更全入审计日志 |

## 5. 验收标准（摘要）

1. 配置外部 OpenLDAP 后，目录账号+密码+TOTP 三要素可登录堡垒机。
2. 目录组 bastion-auditors 成员登录后仅见审计中心（RBAC 矩阵 49 项测试对目录用户复跑通过）。
3. 目录移组后，最迟一次登录/一轮同步内权限收敛。
4. LDAP 服务停机：本地 admin 正常登录，目录用户收到明确错误（<3s），无 5xx。
5. LDAPS 自签证书未配置信任时连接被拒且报错可读。
6. 122 项既有回归 + 新增 LDAP 套件全部通过。
